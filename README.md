# Telegram AI Automation

A simple AI-powered Telegram chatbot workflow built using n8n.

## 🚀 Project Overview

This project connects Telegram with an AI Agent using n8n to automatically receive user messages, process them using an AI model, and send the generated response back to Telegram.

## 🔄 Workflow

Telegram Trigger
↓
AI Agent
↓
Google Gemini Chat Model
↓
Simple Memory
↓
Send Telegram Message

## ✨ Features

- Telegram message automation
- AI-powered responses
- Google Gemini integration
- Conversation memory
- Automatic Telegram replies
- n8n workflow automation

## 🛠️ Technologies Used

- n8n
- Telegram Bot
- Google Gemini
- AI Agent
- Simple Memory

## ⚙️ How It Works

1. User sends a message to the Telegram bot.
2. Telegram Trigger receives the message.
3. AI Agent processes the message.
4. Google Gemini generates the response.
5. Simple Memory maintains conversation context.
6. The response is automatically sent back to Telegram.
